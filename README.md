# ISEYC Civic Brain

**Evidence-grounded civic intelligence and mandate routing (recommendation only)**

Official ISEYC assistant for understanding **published** Civic Mandate Nigeria records and preparing **human-reviewable** institutional routing recommendations.

> *"Empowering Youth, Shaping Communities — Every Street. Every Voice. Accountable Leadership."*

## What it does

- **Civic Intelligence** — questions grounded on public Civic Mandate aggregates (not a national survey)
- **Mandate Routing** — deterministic recommendation of responsible institutions; **never auto-sends**
- **ISEYC Planning** — organisational planning, clearly separated from verified civic evidence

## What it does not do

- Invent published counts or national public opinion  
- Rank candidates or issue awards  
- Contact officeholders or mark referrals as sent without authorised process  
- Deploy itself to production  

## Stack

- React + Vite  
- Serverless `api/chat.js`, `api/route-mandate.js`  
- Optional providers: Groq / Anthropic / xAI (server env only)

## Local development

```bash
npm install
npm test
npm run dev
```
