# Civic Brain ↔ Civic Mandate loop

Civic Brain does not replace Civic Mandate. It reads **Published** public evidence only.

1. Citizens submit demands on Civic Mandate Nigeria.
2. ISEYC moderates; only Published rows enter the public record.
3. Civic Brain answers questions from that public evidence (not unpublished Notion rows).
4. Mandate Routing recommends institutions; humans must review; nothing is auto-sent.

Product URL: https://2027-street-mandate.vercel.app  
Intelligence: https://2027-street-mandate.vercel.app/intelligence

Never claim national public opinion from pilot published counts.
